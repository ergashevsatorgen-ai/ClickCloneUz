## APK'ni GitHub'da yig'ish
1. github.com'da yangi (private) repo oching.
2. ZIP ichidagi BARCHA fayllarni repo ildiziga yuklang (.github papkasi ham!).
3. Repo > Actions > "Build APK" > Run workflow (yoki main'ga push qiling).
4. 5-8 daqiqadan keyin run ichidan "ClickClone-APK" artifact'ni yuklab oling.
5. ZIP'dan app-debug.apk ni chiqarib telefonga o'rnating ("noma'lum manba" ruxsati kerak).

## Android Studio'da
File > Open > shu papka. Sync tugagach: Build > Build APK(s).
